## Reliability notes (for pod-shell.md)

- **Quote-safe send-keys**: stage command in `/tmp/<cycle>.sh` via stdin heredoc.
- **Process-state checks**: `ps -p <pid>` is more reliable than `pgrep -f <regex>` inside outer heredocs (regex chars can break silently).
- **Log buffering**: `tee` to a file always works; `tmux capture-pane` only sees what reached the pane (Python stdout buffering can lag). For long ops, prefer reading the tee'd log file directly.
- **MFS cold-cache cost**: first-time model load on a fresh pod or after volume migration is a real, multi-minute cost. Plan cycle wall-clock budgets accordingly.
